# フォントについて

画面内の日本語表示には **美咲フォント**（美咲ゴシック / 8x8ドット）を使っている。

- 制作: 門真 なむ 氏

## misaki8.bin の作り直し方

`misaki8.bin` は配布元のBDF版から生成したもので、BDF本体はこのリポジトリには含めていない。
作り直す場合は配布元からBDF版のアーカイブを取得し、展開した `misaki_gothic.bdf` を指定して実行する。

```bash
node scripts/build-font.mjs /path/to/misaki_gothic.bdf src/render/font/misaki8.bin
```

生成されるのは固定長の単純なバイナリで、内容は以下のとおり（リトルエンディアン）。

| 位置   | 内容                                           |
| ------ | ---------------------------------------------- |
| `0..3` | マジック `"MSK8"`                              |
| `4..7` | グリフ数 `count` (uint32)                      |
| `8..`  | コードポイント × `count` (uint16, 昇順)        |
| 続き   | 文字幅 × `count` (uint8, 半角4 / 全角8)        |
| 続き   | ビットマップ × `count` × 8バイト（1行1バイト） |
